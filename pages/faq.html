Frequently Asked Questions

What is Helion?

Helion is a next-generation systems programming language that integrates AI, formal verification, and distributed computing into a unified, intuitive system.

Is Helion free?

Yes. Helion is free forever for everyone. It is supported by advertising revenue and open-source contributions.

How is Helion different from Rust?

Helion adds: AI-native primitives, dependent types, algebraic effects, distributed-by-design semantics, and borrowed-by-default (easier than Rust's borrow checker). Rust focuses on memory safety; Helion on the complete programming experience.

Can I use Helion for production?

Not yet. Helion is currently v0.1.0-alpha. We expect production readiness by v1.0 in 2027.

What are the system requirements?

Web: Any modern browser. Android: Android 7.0+ (API 24). Desktop compiler: Coming soon for Windows, macOS, and Linux.

How do AI features work?

Helion has a built-in 'by' operator that sends code specifications to LLMs (GPT-4, Claude, Llama). The generated code is then type-checked and optionally formally verified before execution.

Is Helion open source?

Yes. Apache 2.0 / MIT dual license. The full source code is on GitHub.

How can I contribute?

Submit PRs on GitHub, report bugs, write documentation, create examples, or spread the word.
