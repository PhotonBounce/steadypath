Type System

Helion uses Quantitative Type Theory (QTT) with dependent, linear, and refinement types.

Primitive Types

fn example() { let b: Bool = true; let i: Int = 42; let f: Float = 3.14; let s: String = "Hello"; }

Refinement Types

type Positive = {x: Int | x > 0}; fn divide(x: Int, y: Positive) -> Int { x / y // Safe: y > 0 guaranteed by type }

Linear Capabilities

fn read_file(cap: FileCap, path: &str) -> (FileCap, String) { // cap is consumed and returned - linear type }
