Security Model

Security by capability. Common vulnerabilities are impossible by design.

Capability-Based Security

fn dangerous_operation() requires FileCap + NetworkCap + AICap::budget(100) { // Can only be called with these capabilities }

Memory Safety

  • Buffer overflow: Prevented by dependent types
  • Use-after-free: Prevented by linear types
  • Double-free: Prevented by ownership
  • Null pointer: No nulls in safe code
  • Data races: Prevented by ownership + effects

Information Flow

  • Secret labels tracked through types
  • Declassification requires authorization
  • No implicit flows from Secret to Public
  • Side-channel attack resistance
